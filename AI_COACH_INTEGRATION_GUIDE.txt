========================================
AI CAREER COACH FEATURE - INTEGRATION GUIDE
========================================

This guide shows how to integrate the AI Career Coach feature into your JobTracker application.

========================================
STEP 1: ADD ANTHROPIC API KEY TO CONFIG
========================================

Open config/config.php and add your Anthropic API key:

define('ANTHROPIC_API_KEY', 'sk-ant-your-key-here');

You can get your API key from: https://console.anthropic.com

========================================
STEP 2: CREATE DATABASE TABLE
========================================

Run this SQL command to create the ai_suggestions table:

CREATE TABLE IF NOT EXISTS ai_suggestions (
  id INT AUTO_INCREMENT PRIMARY KEY,
  user_id INT NOT NULL UNIQUE,
  suggestions JSON,
  score INT,
  summary TEXT,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
  INDEX idx_user_id (user_id),
  INDEX idx_created_at (created_at)
);

========================================
STEP 3: FILES CREATED FOR YOU
========================================

The following files have been created:

1. public/ai_analyse.php
   - Backend endpoint that handles the analysis request
   - Fetches analytics data from the Application model
   - Extracts PDF text from user's resume
   - Calls Claude API with the prompt
   - Caches results in the database
   - Returns JSON response

2. public/js/ai-resume.js
   - Frontend JavaScript (IIFE wrapped)
   - Handles button clicks
   - Shows loading state
   - Renders analysis results with animated score ring
   - Displays suggestion cards with color-coding
   - Loads cached data on page load

3. html_snippet_ai_coach_panel.php (this file)
   - The complete HTML/CSS for the AI Coach panel
   - Premium gate for non-premium users
   - Score ring visualization
   - Summary section
   - Suggestion cards grid
   - All styling included

4. sql/migrations/create_ai_suggestions_table.sql
   - Database migration file

========================================
HOW IT WORKS
========================================

1. User clicks "Analyse My Resume" button
2. Frontend sends POST request to ai_analyse.php
3. Backend:
   - Checks if user is premium
   - Fetches all analytics data (applications, conversion rates, etc.)
   - Gets user's default resume (or latest)
   - Extracts text from PDF using pdftotext (with fallback to raw text extraction)
   - Builds a prompt with all the data
   - Calls Claude Sonnet 4 API
   - Parses JSON response
   - Caches result in ai_suggestions table
   - Returns success with data
4. Frontend:
   - Displays animated score ring
   - Shows summary paragraph
   - Renders suggestion cards with color-coding and priority labels
   - Shows "Last analysed X mins ago" if data is cached
5. On next visit, cached data loads automatically

========================================
ERROR HANDLING
========================================

The feature handles these cases gracefully:

- User not premium → shows upgrade prompt
- No resume uploaded → "Upload a resume first" message
- PDF extraction fails → "Could not extract text from resume"
- API error → "AI service unavailable"
- Network error → Shows inline error in panel
- User has < 3 applications → Shows "Add applications for insights"

All errors are user-friendly, not technical dumps.

========================================
TROUBLESHOOTING
========================================

Q: API returns 403 error
A: Check if user is actually premium. Check user.plan in database.

Q: PDF text extraction returns null
A: 
  - Install pdftotext: brew install poppler (macOS) or apt-get install poppler-utils (Linux)
  - Check file permissions on /uploads/resumes/
  - Ensure PDF is valid

Q: Cached data not showing
A: Check ai_suggestions table exists and has data for the user.

Q: "API configuration error"
A: Add ANTHROPIC_API_KEY to config/config.php

Q: Suggestion cards not styled correctly
A: Ensure ai-resume.js and CSS are loaded. Check browser console.

Q: Score ring not animating
A: Check browser supports SVG and CSS animations. Try Force refresh (Ctrl+Shift+R).
